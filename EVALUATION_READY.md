## How to Run Evaluation

```bash

    --device cuda:0 \
    --output_dir results/av_evaluation_comprehensive

# This will:
# 1. Discover all 23 checkpoint directories

# 3. Generate A-V scatter plots
# 4. Save results to results/av_evaluation_comprehensive/
```

## Output Structure

Each plot will be named: `av_scatter_{checkpoint_name}_{fold_or_test}.png`

Example:
- `av_scatter_method2_kfold_fold_1.png` - Method2 on IEMOCAP Fold 1
- `av_scatter_method2_msp_test1.png` - Method2 on MSP-Podcast Test1
- `av_scatter_ssl_baseline_kfold_fold_2.png` - SSL Baseline on IEMOCAP Fold 2

Each plot contains:
- **Left subplot:** True Arousal-Valence (from dataset labels)
- **Right subplot:** Predicted Arousal-Valence (from model predictions)
- **Colors:** Emotion labels (Neutral=blue, Happiness=orange, Sadness=green, Anger=red)

## Metrics Computed

For each checkpoint split:
- **Emotion Accuracy:** Classification accuracy on 4-class emotion labels
- **Arousal CCC:** Concordance Correlation Coefficient for Arousal
- **Valence CCC:** Concordance Correlation Coefficient for Valence
